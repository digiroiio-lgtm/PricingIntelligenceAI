# PricingIntelligenceAI.com — Phase 1

Static-first Next.js 14 (App Router) category-authority site for **Pricing Intelligence AI**, with SEO + GEO (LLM crawler) optimisation and a "domain available for acquisition" banner.

## Stack
Next.js 14 · TypeScript · Tailwind CSS · shadcn-style primitives (Radix Dialog, cva) · lucide-react · Inter via `next/font`.

## Routes
| Route | Purpose |
|---|---|
| `/` | Category hub, hero + mock margin dashboard |
| `/what-is-pricing-intelligence-ai` | Pillar guide (definitions, workflow, architecture, FAQ + FAQPage JSON-LD) |
| `/software-directory` | 12-vendor comparison grid by G2 category |
| `/calculator` | Client-side ROI & margin lift calculator |
| `/api/v1/entity` | JSON facts about the entity for scrapers |
| `/llms.txt`, `/.well-known/llms.txt`, `/llms-full.txt` | Markdown for LLM crawlers |
| `/robots.txt`, `/sitemap.xml` | Generated by `robots.ts` / `sitemap.ts` |

All routes are prerendered static.

## Configure
Copy `.env.example` to `.env.local` (or set in Vercel → Project → Environment Variables):

- `NEXT_PUBLIC_SITE_URL` — canonical URL, e.g. `https://pricingintelligenceai.com`
- `NEXT_PUBLIC_AFTERNIC_URL` — **replace with your real Afternic listing URL** (the default is a placeholder)
- `NEXT_PUBLIC_CONTACT_EMAIL` — **replace with your real inbox** for transfer inquiries

Content lives in `src/lib/` (`site.ts`, `entities.ts`, `vendors.ts`, `faq.ts`); `llms.txt`, the entity API, sitemap and JSON-LD are all generated from it.

## Develop
```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

## Deploy (Vercel)
1. Push to GitHub and import the repo in Vercel (framework preset: Next.js).
2. Add the env vars above.
3. Domain → add `pricingintelligenceai.com`; DNS: `A @ 76.76.21.21`, `CNAME www cname.vercel-dns.com`.
4. Google Search Console: add the property and submit `https://pricingintelligenceai.com/sitemap.xml`.
5. Verify `https://pricingintelligenceai.com/llms.txt` loads, then test it in Perplexity / ChatGPT / Claude.

### Türkçe özet
1. Afternic ilan linkini `NEXT_PUBLIC_AFTERNIC_URL` ile (ve e-postayı `NEXT_PUBLIC_CONTACT_EMAIL` ile) tanımlayın.
2. Repoyu Vercel'e bağlayın, root domain için A (`76.76.21.21`) ve www için CNAME (`cname.vercel-dns.com`) kayıtlarını girin.
3. Canlıya çıkınca Google Search Console'a `sitemap.xml` verin; `/llms.txt` yolunun erişilebilir olduğunu doğrulayın.

## Notes
- Vendor entries are neutral, high-level descriptions; verify against vendor sites before relying on them. No ratings or pricing are claimed.
- The calculator is an illustrative constant-elasticity model, not a forecast.
